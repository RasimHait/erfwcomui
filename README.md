# ERFW Companion UI

Интерфейс приложения ERFW Companion. Публикуется через GitHub Pages и открывается внутри приложения в WebView2.
В обычном браузере страница показывает все состояния по кругу.

- `index.html`, `style.css`, `app.js` — окно состояния и заголовок окна.
- `bridge.js` — обмен сообщениями с приложением:
  - `erfw.on(type, handler)` — подписка на сообщения приложения, возвращает функцию отписки; значение, возвращённое обработчиком, уходит ответом на запрос приложения;
  - `erfw.send(type, data)` — сообщение приложению без ответа;
  - `erfw.request(type, data, ms)` — запрос к приложению, `Promise` с ответом;
  - `erfw.hosted` — страница открыта внутри приложения;
  - `erfw.minimize()`, `erfw.close()` — свернуть и закрыть окно.

  Сообщения в обе стороны — JSON: `{ type, data }`, запрос `{ type, data, id }`, ответ `{ replyTo, data }` или `{ replyTo, error }`.

  Сообщения приложения:
  - `status` — `{ state, text, detail }`, состояние подключения;
  - `trpProfiles` — `{ character, current, profiles: [{ id, name, updated }] }`, профили TRP текущего персонажа.

  Запросы страницы:
  - `runTestCode` — выполнить тестовый код, ответ `true`, если код ушёл в аддон;
  - `trpApply` — `id` профиля, ответ `true`, если профиль ушёл в аддон.
  - `trpDelete` — `id` профиля, удаляет сохранённую копию, ответ `true`, если удалено. Активный профиль не удаляется.
  - `trpReorder` — массив `id` в нужном порядке, порядок сохраняется в файле персонажа.

  На странице: клик по профилю делает его активным, правая кнопка открывает меню, перетаскивание и Alt+↑/↓ меняют порядок.
- `dictionaries/` — словари Hunspell для проверки орфографии. Приложение скачивает их при запуске
  и перекачивает файлы, у которых изменился размер.
