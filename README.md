# ERFW Companion UI

Интерфейс приложения ERFW Companion. Публикуется через GitHub Pages и открывается внутри приложения в WebView2.
В обычном браузере страница показывает все состояния по кругу.

- `index.html`, `style.css`, `app.js` — окно состояния и заголовок окна.
- `bridge.js` — обмен сообщениями с приложением, описание API в начале файла.
